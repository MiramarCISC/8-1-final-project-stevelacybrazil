
# Pokemon Card Collection Tracker

## Project Description

This project is a simple Pokemon Card Collection Tracker.

The program loads Pokemon cards from a file and allows the
user to view their collection, search for a Pokemon card,
sort cards by price, and calculate the total value of the
collection.

The program also stores card searches in a linked list to
demonstrate pointers and dynamic memory.

## How to Compile

```bash
make
./main
```

## Run Tests

```bash
make test
```
